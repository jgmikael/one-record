What is One Record?

This demo implements a fcior-aligned canonical business document layer for transforming SAP Orders into semantically grounded JSON-LD documents.

Local Setup

⚡ Interactive Features (Local Only)

The full demo includes:

  • Import custom SAP orders
  • Live transformation engine
  • REST API access
  • Database persistence

Prerequisites

  • Node.js 18 or higher
  • npm 8 or higher
  • Git

Quick Start (3 commands)

# 1. Clone repository
git clone https://github.com/jgmikael/one-record.git
cd one-record

# 2. Setup & Start
npm run demo

# 3. Open browser
http://localhost:3001/#import?sample=true

Alternative: Docker

# Using Docker Compose
docker-compose up -d

# Or build yourself
docker build -t one-record-demo .
docker run -p 3001:3001 one-record-demo

# Access at: http://localhost:3001
