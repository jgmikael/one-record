About This Demo

            

                
What is One Record?

                

                    This demo implements a fcior-aligned canonical business document layer 
                    for transforming SAP Orders into semantically grounded JSON-LD documents.
                


                
Key Technologies

                
    
                    
  • fcior - Finnish Construction Industry One Record (UBL Order subset)
    • 
                    
  • busdoc - Finnish business document vocabulary (EN 16931-1 compliant)
    • 
                    
  • JSON-LD - Linked Data format with semantic context
    • 
                    
  • W3C VC-compatible - Ready for cryptographic signatures
    • 
                


                
Semantic Vocabularies

                
    
                    
  • fcior vocabulary
    • 
                    
  • busdoc vocabulary
    • 
                


                
How It Works

                
    
                    
  1. Import SAP Order JSON
    2. 
                    
  2. Mapping engine applies 60+ curated transformation rules
    3. 
                    
  3. Generate fcior-aligned canonical JSON-LD
    4. 
                    
  4. Store both SAP source and canonical form
    5. 
                    
  5. Provide explainable mapping report with confidence scores
    6. 
                


                
Features

                
    
                    
  • ✅ Complete field-level traceability
    • 
                    
  • ✅ Confidence scoring for each mapping
    • 
                    
  • ✅ Semantic references to fcior/busdoc vocabulary
    • 
                    
  • ✅ Dual persistence (SAP + canonical)
    • 
                    
  • ✅ Profile versioning for evolution
